# M1 - Smart Rent Prediction

## 1. Purpose

M1 (Smart Rent Prediction) predicts the monthly rental price of a property using property characteristics and location-related features.

The prediction is based on the finalized M1 dataset prepared from the Avenue360 AI/ML data.

---

## 2. Dataset

Dataset:

`M1_Rent_Prediction_final.csv`

Rows:

`10,000`

Input features:

`23`

Target:

`current_listing_rent`

The final dataset is generated after enriching the base M1 dataset with `property_type`, correcting logical floor inconsistencies, and removing identifier and excluded leakage-prone fields.

---

## 4. Dataset Preparation

The final M1 dataset is generated by the dataset preparation module.

### Steps

1. Load `M1_Rent_Prediction.csv`.
2. Load `properties_enriched.csv`.
3. Add `property_type` using `property_id`.
4. Detect logical floor inconsistencies where `floor > total_floors`.
5. Correct those inconsistent records.
6. Remove `property_id`.
7. Remove excluded leakage-prone fields:
   - `average_recent_historical_rent`
   - `historical_rent_change_pct`
   - `market_rent_index_latest`
8. Save the finalized dataset as:

`M1_Rent_Prediction_final.csv`
